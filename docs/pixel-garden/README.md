# 周 / 月像素花园

独立实现的 GPL-3.0-or-later 开源组件，安装在 Butterfly 头像卡片的 GitHub / 博客园按钮下方。无运行时依赖，无需修改或脱离主题子仓库。周 / 月视图使用内置图片生成工具创作的透明像素素材，场景和独立徽章使用原创 SVG，不调用 Forkest，也没有复制其图像或代码。

## 生长规则

一周按配置时区的周一至周日排列，每株植物代表一天的 GitHub 贡献数量：

| 每日贡献 | 植物 |
| --- | --- |
| 0 | 土中的种子 |
| 1–2 | 萌芽 |
| 3–5 | 展叶 |
| 6–9 | 含苞 |
| ≥10 | 盛放；秋季带果实 |

本周总数与上周相同天数的总数比较，不拿未结束的一周与完整上周比较。点击每个星期标签可查看日期、贡献数和生长阶段。未来日期用 `·` 和空土表示；缺失数据用 `?`，不会冒充零贡献。

北半球：3–5 月为春、6–8 月为夏、9–11 月为秋、12–2 月为冬。季节改变天空、山丘、土壤、叶片与花朵的颜色，冬季还有积雪；南半球相反。这是按月份划分的视觉季节。

## 视图、微风与滑动

- **周视图**使用与月视图同画风的侧视植物图片，保留原来的山丘和土壤。只有植物轻微随风摇摆，根部与土壤保持固定，不同植物的摆动错开。
- **月视图**沿用四季配色，使用原创俯视灌木地块；按周一至周日排列，每格代表当天贡献，右下角显示日号。月历固定六行，切换月份时高度稳定。四季分别采用樱花团簇、宽圆叶冠、尖角枫叶和星形针叶积雪，轮廓与颜色共同区分季节。
- 卡片**右下角的 Week / Month 按钮**切换视图，浏览的日期会保留；访问时记住上次选择的视图。点击日期显示其贡献与生长阶段，不再默认显示额外说明段落。
- 两种视图都可连续横向滑动，**不强制整周或整月吸附**。鼠标拖动画面、触摸左右滑动、触控板横向滚动、`Shift + 滚轮`，或者拖动底部的小滚动条均可浏览。
- 滚动条对应当前展开的日期窗口，拖到边缘松开会接着展开前后日期。页面仅保留七个相邻时间段的空容器，只有可见的一到两个时间段生成 SVG 和日期按钮，移出视口即卸载。容器保留相同高度，切换时不会跳动；滚动到窗口边缘时复用现有可见面板。
- 历史日期会显示 `Today` 按钮。花园获得键盘焦点后，左右方向键连续移动，`Home` 返回当前周 / 月。
- 历史浏览超过已有年度数据时，按需读取公共 API 的对应年份并缓存一天。读取失败或禁用 `live_refresh` 时仍能滑动，缺失日期继续显示 `?`；未来日期不会伪装成零贡献。2008 年之前不发起 GitHub 历史请求。
- 浏览历史时季节随所选日期变化；周 / 月统计与上个时间段相同天数比较，较短月份只比较双方都有的日期。徽章仍保持当前周。
- 月视图灌木保持静止，减少同时运动的图片；每个周面板最多七株植物摇摆。浏览器开启“减少动态效果”时停止摇摆并隐藏天气粒子。离开可视区的花园卸载画面。

## 英文界面与季节氛围

花园卡片使用 `Weekly Garden` / `Monthly Garden` 英文标题，季节、星期、贡献统计和切换按钮也统一为英文。月视图保留 32 像素地块，四个生长阶段的基础显示区域为 8 / 13 / 19 / 24 像素。头像卡片里的月视图（包括手机）默认放大 1.5 倍，主栏大图保持基础尺寸。树冠绘制在全部地块上方，允许自然跨格重叠；边缘树冠保留在整幅画面内。

每季一张透明 PNG，包含萌芽、小树冠、成长期和成熟期四个阶段，按左上、右上、左下、右下排列。春季粉色樱花带暖色花心，夏季是宽圆绿叶冠，秋季金棕枫叶带橙色果实，冬季星形针叶带分层积雪。生成后仅调整配色，向 Weekly Garden 的叶色、花色和雪色靠齐；完整提示词保存在 [SPRITE-PROMPTS.md](SPRITE-PROMPTS.md)。

素材保存在 `source/garden/sprites/`，月视图尺寸与文件名由 `manifest.json` 声明，周视图由 `weekly-manifest.json` 声明。每季每种视角复用一张图集，SVG 的 `viewBox` 选取对应阶段，保留原 PNG 的透明度。周视图使用各阶段的透明边界作为显示区域，将根部固定在地面；放大后允许相邻树冠重叠。只在可见时间段创建图片节点，没有预加载所有季节。周视图素材配置缺失时使用保留的原生 SVG 植物；月视图旧 SVG 灌木已移除，素材配置缺失时显示已知贡献数，零贡献、未知与未来日期继续区分。独立徽章继续使用原植物造型，避免外部图片依赖。

周和月的画面中增加按所选季节生成的装饰动画：春季细雨、秋季棕色小落叶、冬季简约白色雪点；夏季保持清朗。它们是季节氛围，未接入实时天气 API，也不代表某地的实际天气。无需位置权限或额外网络请求，滑动到历史日期时也能保持对应季节的视觉效果。

粒子数量固定且少量，秋叶在下落途中左右摆动，幅度与周期错开，并轻微翻转。所有天气粒子都被限制在画面内，不覆盖日期按钮或接管鼠标事件。花园画面离开浏览器视口或标签页切到后台时，卸载全部植物、日期按钮和粒子，回到可见位置后重建。开启“减少动态效果”后隐藏飘落粒子并停止植物摇摆。日期模型缓存在当前七个时间段内，滚动帧复用已有数据，数据更新时刷新缓存。

## 后续视觉约定

继续修改花园时，优先复用 `pixel-garden-core.js` 中的四季配色、32 像素地块和整数坐标。场景保持低饱和度的自然色、方形像素边缘、分层山丘与土壤纹理；新增花、果实、天气和控件沿用同一套颜色和像素尺度。

周视图使用侧视植物生长阶段，月视图使用俯视灌木地块。两者通过配色、像素尺度和细节保持一致，各自的视角继续保留。周视图微风只轻动植物，土壤与根部固定，延续平缓、错开节奏的动画；月视图植物静止。

## 桌面显示位置与动画参数

桌面右下角齿轮的展开菜单增加植物按钮，可切换头像卡片与主栏大图，并在本地记住选择。文章页将同一个 `#pixel-garden` 节点移入 `#post`，放在 `.relatedPosts` 后、`#post-comment` 和其分隔线前；未启用评论时放在文章主容器末尾。首页放在 `#recent-posts` 的文章列表前。移动同一节点可保留周 / 月模式、浏览日期和数据，无需创建第二份花园。窗口宽度不超过 900px 时自动回到头像卡片并隐藏位置按钮，桌面选择仍被保留。

植物摇摆参数：

- `source/js/pixel-garden-core.js` 的 `renderScene`：`--pg-wind-duration` 当前为 `4.2 + index % 3 * .6` 秒，增大 `4.2` 会减慢；`.6` 是不同植物的周期差。`--pg-wind-delay` 的 `.63` 用于错开节奏。
- `source/css/pixel-garden.css` 的 `@keyframes pg-wind`：`skewX(-1.5deg)`、`skewX(2deg)`、`skewX(.5deg)` 控制摇摆幅度，角度绝对值越大越明显。`.pg-plant` 的 `4.8s` 仅为缺少上述参数时的备用周期。
- `pixel-garden-core.js` 的 `renderWeather`：季节 `duration` 控制粒子下落周期；`--pg-flutter-width` 控制秋叶左右幅度，`--pg-flutter-duration` 控制左右摆动周期。CSS 的 `@keyframes pg-leaf-flutter` 控制翻转角度。
- 月视图灌木保持静止，以上植物摇摆设置作用于周视图。

`source/js/pixel-garden.js` 顶部的 `SIDEBAR_WEEKLY_PLANT_SCALE = 2` 控制侧视植物，`SIDEBAR_MONTHLY_PLANT_SCALE = 1.5` 控制俯视灌木。仅头像卡片里的对应视图使用这些倍率（包括手机）；文章主栏大图两者都使用 `1`。对应接口是 `renderScene(week, sheet, { plantScale })` 和 `renderMonth(month, sheet, { plantScale })`。切换位置时重新绘制可见面板，保留日期和模式。旧月视图的 `makeShrubArt` / `renderShrub`、专用颜色与图形缓存已清理；周视图的原生 SVG 与独立徽章仍保留。

## 配置

主配置 `_config.yml`：

```yaml
pixel_garden:
  enable: true
  username: rD227
  timezone: Asia/Shanghai
  hemisphere: north # north / south
  live_refresh: true
```

主题配置通过 `inject.head` 引入 `/css/pixel-garden.css`，通过 `inject.bottom` 按顺序引入 `/js/pixel-garden-core.js`、`/js/pixel-garden.js`。若安装在网站子路径，给这些注入路径及第二个脚本的 `data-config` 加上站点前缀。关闭 `enable` 后不再生成花园配置、数据和 SVG，也不会挂载组件。

## 数据与更新

- 构建时读取 [GitHub 的公开贡献日历](https://github.com/users/rD227/contributions)，不需要令牌。日期和贡献数保留 GitHub 的统计口径；配置时区决定组件的“今天”和周边界，并不重新归属 GitHub 已统计的贡献。
- 生成 `garden/data.json`、`garden/config.json` 与 `garden/week.svg`。构建失败时尝试读取 `.cache/pixel-garden/` 的本地缓存，并标记缓存状态；全无数据时显示不可用状态。
- 可选的访客端更新使用 [GitHub Contributions API](https://github.com/grubersjoe/github-contributions-api)，这是独立的开源公共服务，并非 GitHub 官方 API；它缓存约一小时。组件也缓存一小时，访客请求不包含凭据，数据中只有日期和数量。禁用 `live_refresh` 可只使用本地生成的数据。
- 公共 API 超时、离线、浏览器禁用存储时，仍可使用本地快照。页面标注数据更新时间，旧快照标注“缓存”，本周缺失数据标注待更新。
- Pages 工作流新增每日北京时间 08:17 的构建部署计划；实际运行时间取决于 GitHub Actions 调度。需要将修改提交到默认分支，计划任务才会启用。长期无活动的仓库可能需要在 Actions 中重新启用计划任务。
- 跨日及跨周后页面会按新日期重绘，并尝试刷新数据。支持 `pjax:complete`，重复初始化不重复插入。

普通 SVG 徽章可通过以下形式复用：

```markdown
[![一周像素花园](https://rd227.github.io/garden/week.svg)](https://github.com/rD227)
```

SVG 徽章在网站重新构建时更新；卡片中的组件还可以使用可选公共 API 刷新。第三方使用徽章时也可能受图片代理缓存影响。

## 文件与许可范围

本目录的 GNU GPL v3 或更新版本许可覆盖此组件的代码、文档与随附原创素材：

- `source/js/pixel-garden-core.js`：日期、季节、生长阶段和原创像素 SVG；同时可用于 Node.js 与浏览器。
- `source/js/pixel-garden.js`：数据、缓存、头像卡片挂载及交互。
- `source/css/pixel-garden.css`：明暗主题和自适应卡片样式。
- `scripts/pixel-garden.js`：Hexo 构建数据和独立徽章。
- `source/garden/sprites/`：四季原创生成素材与尺寸清单。
- `tests/pixel-garden.test.cjs`：日期边界、数据解析和失败回退验证。
- 本目录文档与许可。

不更改博客文章和 Butterfly 主题已有的许可证。运行 `node --test tests/pixel-garden.test.cjs` 验证逻辑，运行 `npm run build` 生成博客。
